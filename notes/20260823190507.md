# Run a Django management command from another command

You can use `call_command` to chain management commands, great for bundling related jobs under a single cron entry instead of scheduling each one separately. Pass `stdout=self.stdout` so the child's output flows into the same run.

```python
from django.core.management import call_command
from django.core.management.base import BaseCommand


class Command(BaseCommand):
    def handle(self, *args, **kwargs):
        # ... do the main work, send the weekly stats email ...
        self.stdout.write(self.style.SUCCESS("Weekly stats sent."))

        # chain a second command — one cron entry runs both
        call_command("forum_comments_digest", stdout=self.stdout)
```
