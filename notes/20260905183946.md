# Cron jobs inside a long-running app with APScheduler

Process already runs forever (Slack bot, web server, worker) and you want "every Monday at 9"? No system cron, no blocking `while True`. `BackgroundScheduler` runs jobs on its own thread, right next to your main loop.

```python
from apscheduler.schedulers.background import BackgroundScheduler
from apscheduler.triggers.cron import CronTrigger

scheduler = BackgroundScheduler(timezone="Europe/Amsterdam")
scheduler.add_job(
    weekly_nudge,
    CronTrigger.from_crontab("0 9 * * mon", timezone="Europe/Amsterdam"),
    misfire_grace_time=3600,  # still fires if we were down at 09:00 (redeploy)
)
scheduler.start()  # non-blocking
```

Plain cron syntax, timezone-aware, and `misfire_grace_time` covers a brief redeploy at trigger time.

Gotcha: use the weekday *name* (`mon`), not the number. `from_crontab` reads numeric day-of-week as APScheduler's 0=Mon..6=Sun, so `"0 9 * * 1"` fires Tuesday, not cron's Monday. Names sidestep the ambiguity.
