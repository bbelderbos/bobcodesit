# Drip-release commits by pushing one at a time

When your local `main` already contains the whole project as a clean, linear
history (one commit per "chapter"), you don't need branches or feature flags to
release it gradually. `origin/main` only shows what you've pushed, so you can
advance the public branch one commit at a time. Anyone cloning gets exactly the
history up to that point — they can't `git log` ahead.

The key detail: push a *commit* (not a branch) to a branch ref, which needs the
fully-qualified `refs/heads/` destination.

```bash
# tag each chapter's commit once (tags stay local, so they don't leak what's next)
git tag week1 ce2939b
git tag week2 d34f590

# release chapter 1 — creates origin/main at that commit
git push origin week1^{commit}:refs/heads/main

# next release date: fast-forward the public branch by one commit
git push origin week2^{commit}:refs/heads/main
```

`week1^{commit}` dereferences the tag to the commit it points at. Each push is a
fast-forward, so it's safe and reversible-ish (you control how far main moves).
Great for a course, a book, or a launch where content unlocks on a schedule.
