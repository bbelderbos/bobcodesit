# Store a weekly schedule as a 7-bit integer

When a habit (or any recurring thing) can happen on any subset of weekdays, don't reach for a related table or seven boolean columns. Pack the whole week into one small integer: bit *i* = weekday *i* is "on". `date.weekday()` gives Mon=0..Sun=6, so `1 << day.weekday()` is that day's bit, and a bitwise AND answers "is it due?".

The nice part: the storage is fully granular (any of the 128 combinations), but the UI can expose just two presets — Daily and Weekdays — with zero migration needed to go fully custom later.

```python
from datetime import date

ALL_DAYS = 0b1111111  # 127 -> every day
WEEKDAYS = 0b0011111  # 31  -> Mon-Fri (bits 0-4)

def is_due_on(due_days: int, day: date) -> bool:
    return bool(due_days & (1 << day.weekday()))

gym = WEEKDAYS
assert is_due_on(gym, date(2026, 6, 12))      # Friday  -> True
assert not is_due_on(gym, date(2026, 6, 13))  # Saturday -> False

# Count due days in a range (e.g. for a completion rate denominator)
def due_days_between(due_days, start, end):
    from datetime import timedelta
    d, n = start, 0
    while d <= end:
        n += is_due_on(due_days, d)
        d += timedelta(days=1)
    return n
```

In Django it's just `models.PositiveSmallIntegerField(default=ALL_DAYS)` — one column, no join, and streak/calendar logic filters days through the same `is_due_on` predicate.
