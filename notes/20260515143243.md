# Rust's `HashMap::entry().or_insert(0)` is the closest thing to `collections.Counter`

Counting things in Python is a one-liner:

```python
from collections import Counter
counts = Counter(text.split())
```

Rust does not give you that conciseness, but the `entry` API gets close, and it's worth knowing because the pattern generalizes far beyond counting (grouping, memoizing, lazy init):

```rust
use std::collections::HashMap;

fn word_count(text: &str) -> HashMap<String, usize> {
    let mut map: HashMap<String, usize> = HashMap::new();
    for word in text.split_whitespace() {
        *map.entry(word.to_string()).or_insert(0) += 1;
    }
    map
}
```

Read it as: "give me the entry for this key; if it doesn't exist, insert `0`; either way, deref it (`*`) so I can `+= 1`."

The Python equivalent without `Counter` would be `dict.setdefault(word, 0)`, and `entry().or_insert()` is the same idea: avoid the "check, then insert" two-step. One lookup, one branch, done.

Once `entry` clicks, a lot of "if key in d:" Python code starts to feel clunky.
