# contextvars for per-request state in async Python

Module-level globals leak across users in any concurrent service — even with a `threading.Lock`. The lock makes each op atomic, but there's still only one counter shared by every thread and every asyncio Task. Two users hitting the same agent, and userA's tool-call budget gets eaten by userB's increments.

`threading.local` doesn't save you under asyncio either: every Task runs on the same thread, so they all share one `threading.local` slot. `contextvars.ContextVar` keys on *context* instead, and `asyncio.Task` copies the context on creation — each Task gets its own copy.

## The leak

```python
import asyncio

_call_count = 0
_sources: list[str] = []

async def tool_call(user: str, i: int) -> None:
    global _call_count
    _call_count += 1
    _sources.append(f"{user}:q{i}")
    await asyncio.sleep(0)

async def run(user: str) -> None:
    for i in range(3):
        await tool_call(user, i)
    print(f"[{user}] count={_call_count} sources={_sources}")

async def main() -> None:
    await asyncio.gather(run("A"), run("B"))

asyncio.run(main())
```

```text
[A] count=6 sources=['A:q0', 'B:q0', 'A:q1', 'B:q1', 'A:q2', 'B:q2']
[B] count=6 sources=['A:q0', 'B:q0', 'A:q1', 'B:q1', 'A:q2', 'B:q2']
```

Both users see each other's data. The counter is doubled, sources are interleaved.

## The fix

```python
import asyncio
import contextvars

_call_count: contextvars.ContextVar[int] = contextvars.ContextVar("count", default=0)
_sources: contextvars.ContextVar[tuple[str, ...]] = contextvars.ContextVar("sources", default=())

async def tool_call(user: str, i: int) -> None:
    _call_count.set(_call_count.get() + 1)
    _sources.set(_sources.get() + (f"{user}:q{i}",))
    await asyncio.sleep(0)

async def run(user: str) -> None:
    for i in range(3):
        await tool_call(user, i)
    print(f"[{user}] count={_call_count.get()} sources={list(_sources.get())}")

asyncio.run(asyncio.gather(run("A"), run("B")))
```

```text
[A] count=3 sources=['A:q0', 'A:q1', 'A:q2']
[B] count=3 sources=['B:q0', 'B:q1', 'B:q2']
```

Each Task got its own copy of the context on creation. No lock, no `reset()`, no leak.

One subtle trap: `ContextVar(default=[])` shares the *same* list object across every context that hasn't called `.set()`. A stray `cv.get().append(x)` silently mutates that default and leaks across contexts. Use a tuple as the default and rebuild with `.set()` — immutable defaults make the mistake non-expressible.
