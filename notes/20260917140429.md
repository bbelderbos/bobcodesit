# Let the Rust compiler list every undocumented public item

Writing a nice `//!` crate overview with `[`links`]` to your public API can hide a trap: the links resolve, but each one lands the reader on a page with zero prose.

Instead of hunting for bare items by eye, make the compiler do it. Add `#![warn(missing_docs)]` to the top of `lib.rs` and `cargo build` prints one warning per undocumented public item — type, field, enum variant, method, the lot.

```rust
#![warn(missing_docs)]

/// A single lexical unit scanned from the input.
pub enum Token {
    /// `{`
    LeftBrace,
    LeftBracket, // warning: missing documentation for a variant
}

// compiler will complain about the missing docs for `LeftBracket`:

warning: missing documentation for a variant
 --> src/tokenizer.rs:8:5
  |
8 |     LeftBracket,
  |     ^^^^^^^^^^^
```

Work the list to zero, then keep the attribute in as a guard — new public items now fail the same check. Count what's left with `cargo build 2>&1 | grep -c 'missing documentation'`. Bonus: give fallible `pub fn`s a `# Errors` section — rustdoc renders it as its own heading, and it's the first thing a caller of your Quick Start example needs.
