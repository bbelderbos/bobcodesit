# Use contextlib.suppress instead of try/except/pass

EAFP: "Easier to Ask for Forgiveness than Permission."

It's the Pythonic way, but `try/except/pass` is ugly. `contextlib.suppress` makes it clean: one line to say "do this, ignore if it fails." Works with multiple exception types.

For "try/except/pass" patterns? Perfect fit.

```python
from contextlib import suppress
import os

# Instead of try/except/pass
with suppress(FileNotFoundError):
    os.remove("temp.txt")

# Multiple exceptions
with suppress(KeyError, IndexError):
    value = data["key"][0]

# Common pattern: close if exists
with suppress(AttributeError):
    connection.close()
```
