# Declare your module's public API with `__all__`

Using `from module import *` is generally bad practice: it pollutes your namespace, creates name collisions, and hides where imported names came from.

While you can't strictly stop someone from star-importing your package, you can control what gets pulled in by using `__all__`:

```python
# mod.py
__all__ = ["a", "b"]


def a():
    pass


def b():
    pass


def c():
    pass
```

```python
>>> from mod import *
>>> a()
>>> b()
>>> c()
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'c' is not defined
```

Direct imports like `from mod import c` still work fine; `__all__` only controls star imports.

It also offers clear documentation, explicitly showing consumers what your public API is vs. internal helper code.

And linters like Ruff use it too when checking for unused imports. 💡
