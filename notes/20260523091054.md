# Use a frozen dataclass for immutable result value objects

When a function returns a result that should never be mutated after creation, `@dataclass(frozen=True)` is the right shape — not a Pydantic `BaseModel`. It's lighter, clearly signals immutability, and prevents accidental field reassignment.

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class ClassificationResult:
    response: ExpenseCategorizationResponse
    persisted: bool

# Attempting mutation raises FrozenInstanceError at runtime
result = ClassificationResult(response=resp, persisted=False)
result.persisted = True  # FrozenInstanceError
```

Use a plain `@dataclass` (mutable) for service/handler objects that hold dependencies. Use `frozen=True` for value objects that represent the outcome of one operation.
